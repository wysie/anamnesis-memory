# Anamnesis v0.1 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build the first deterministic local memory core for Anamnesis: SQLite schema, scoped writes, FTS recall, invalidations, and audit events.

**Architecture:** A lightweight Python package stores curated memory records in SQLite with an FTS5 index. Recall is deterministic and scope-filtered before ranking. Local LLM support is explicitly out of scope for v0.1.

**Tech Stack:** Python 3.11+, SQLite/FTS5, pytest.

---

## Task 1: Schema bootstrap

**Objective:** Create database tables and initialize the FTS index.

**Files:**
- Create: `src/anamnesis/core.py`
- Test: `tests/test_core.py`

**Steps:**
1. Write failing test: creating `Anamnesis(db_path)` creates `memories`, `memory_fts`, and `audit_log` tables.
2. Run targeted test and verify it fails because `core.py` has no implementation.
3. Implement minimal schema initialization.
4. Run targeted test and full suite.
5. Commit.

## Task 2: Add memory records

**Objective:** Store semantic memories with owner/platform/visibility metadata and mirror them into FTS.

**Files:**
- Modify: `src/anamnesis/core.py`
- Test: `tests/test_core.py`

**Steps:**
1. Write failing test for `add_memory(...)` returning a `MemoryRecord`.
2. Assert memory appears in `memories` and `memory_fts`.
3. Implement minimal write path and write audit event.
4. Run tests.
5. Commit.

## Task 3: Scoped recall

**Objective:** Recall memories by keyword only after owner/platform/visibility scope filtering.

**Files:**
- Modify: `src/anamnesis/core.py`
- Test: `tests/test_core.py`

**Steps:**
1. Write failing test with two memories: one visible, one out of scope.
2. Assert only visible memory is recalled.
3. Assert recall result contains reasons including `keyword_match` and `scope_match`.
4. Implement FTS recall and deterministic score.
5. Run tests.
6. Commit.

## Task 4: Invalidates

**Objective:** Invalidated memories must disappear from recall but remain in storage and audit log.

7. Commit.
